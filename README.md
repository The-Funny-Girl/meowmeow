# Kirkware source tree

This repository contains the original Windows source/build assets plus an in-progress native Linux port.

For Linux, start with [BUILDING-LINUX.md](BUILDING-LINUX.md). The Linux target uses CMake/C++20 and does not require the Windows PowerShell/PE build pipeline.

Current Linux migration status is tracked in [docs/LINUX_PORT_STATUS.md](docs/LINUX_PORT_STATUS.md).
